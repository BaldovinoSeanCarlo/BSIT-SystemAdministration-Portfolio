# Euphoria Solutions – Enterprise Infrastructure Planning

## Project Overview

This project presents an Enterprise Infrastructure Plan for NexaCore Solutions, a fictional software development startup with 20 employees.

The objective of the project is to design the company's foundational IT infrastructure before equipment and services are purchased.

## Learning Objectives

- Analyze organizational IT requirements.
- Prepare hardware, software, and network inventories.
- Design an enterprise network topology.
- Understand system administration roles.
- Develop infrastructure recommendations.
- Create professional technical documentation.

## Company Scenario

Euphoria Solutions is a software development and IT solutions startup located in Santa Rosa, Laguna.

The company has 20 employees distributed among:

| Department | Employees |
|---|---:|
| Information Technology | 5 |
| Human Resources | 4 |
| Finance | 5 |
| Sales | 6 |
| Total | 20 |

The network consists of:

Internet → ISP Modem → Router → Firewall → Managed Switch

## Challenges Encountered

The main challenge was designing a network that could support all four departments while remaining organized and scalable. Another challenge was determining appropriate hardware and software based on the company's actual requirements.

## Reflection

This project helped me understand the importance of planning before deploying an IT infrastructure. I learned how to analyze business requirements, create inventories, design a network topology, and recommend appropriate technologies.
